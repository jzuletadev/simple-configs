## Convenciones

- Los comandos están listos para copiar y pegar, sin prefijos de prompt.
- En Linux, lo único que cambia entre Ubuntu y Arch suele ser la instalación.
  La configuración (git, ssh, aws, docker compose, etc.) es idéntica en ambos.
- Donde dice "común (Linux)", aplica igual en Ubuntu y Arch.
