# Document style

Apply these rules whenever you produce a deliverable document.

## Format

- Body: Arial 12, 1.15 line spacing, justified text.
- Headings: bold Arial, color black. H1 16 pt, H2 13 pt, H3 11 pt.
- Never put lines or borders under headings or subheadings, nor in the header or footer.
- Always use a defined style (fonts and colors); never plain default formatting.
- Figures and tables, numbered separately (Figure 1, Figure 2...; Table 1, Table 2...; Figura and Tabla in Spanish documents):
  - Above each one, left-aligned: the label on one line and its title on the next.
  - Below each one, a note in Arial 10, italic, black, left-aligned, 1.0 line spacing and no space before or after. It starts with the word Note followed by a period (Nota. in Spanish documents).
- References: APA 7th edition, with hanging indent, Arial 10, justified text.

## Writing

- Write the document in neutral, academic Spanish, in the impersonal third person, unless the user asks for another language.
- Direct sentences, without filler or stock phrases ("en el mundo actual", "es importante destacar").
- Short paragraphs; bullets only when they make reading easier.
- Don't invent data or sources. If a fact is missing, mark it as [PENDIENTE].

## Before delivering

- If there is a brief, rubric or list of requirements, check the document against it point by point.
- Every figure and table is numbered and mentioned in the text.
- Every in-text citation has its reference, and every reference is cited.
- Tell the user what is missing or partial and list any [PENDIENTE] left in the document.
