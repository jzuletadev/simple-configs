# Project instructions template (claude.ai)

Create one Project per area of work (a product, a client, a course or a long report) and paste this into its instructions.
Replace what is in brackets. Upload the brief, the requirements or rubric, and the reference material to the Project.

```text
Goal: [WHAT HAS TO BE DELIVERED AND FOR WHOM].
Deadlines: [DATES OR MILESTONES].
My role: [ROLE]. If the work is shared, focus on my part unless I ask for the rest.

Sources: the files in this Project come first, in this order: brief, requirements or rubric, reference material. If they contradict each other or something is ambiguous, tell me before assuming.

Quality control:
- Before starting a deliverable, list the requirements you will check it against.
- Before delivering, review it against that list and show what is covered, partial or missing.
- Never invent data, quotes or references; mark missing facts as [PENDIENTE].
- For deliverable documents apply the document-style skill.

Decisions: when we decide something (scope, approach, structure), close your reply with one line starting with "Decision:". If a later request contradicts an earlier decision, point it out.
```
